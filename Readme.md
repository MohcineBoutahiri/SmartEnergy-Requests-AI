# ⚡ SmartEnergy Requests AI

SmartEnergy Requests AI is an intelligent web application designed to automate 
and optimize the processing of customer requests in the gas and electricity sector 
using Machine Learning and Artificial Intelligence.

---

## 🎯 Project Objective

The goal of this project is to automatically analyze customer requests submitted 
through digital channels and provide intelligent decision-making support, reducing 
manual processing time and improving customer experience.

---

## 🧠 Key Features

### 👤 Customer Side
- Submit service requests (subscription, cancellation, complaint, modification)
- Provide personal information and consent
- Track request status in real time
- Simple and intuitive web interface

### 🛠️ Administrator Side
- Dashboard with request statistics
- Automatic classification of requests using Machine Learning
- View AI confidence scores and extracted information
- Approve, reject, or request additional information
- Manage customer accounts and requests
